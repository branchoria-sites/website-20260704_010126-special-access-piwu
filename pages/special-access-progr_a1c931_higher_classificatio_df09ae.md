## Introduction

Special access programmes, or SAPs, are often described in popular language as “above Top Secret”. That phrase is memorable, but it is technically misleading. In the United States classification system, Top Secret is the highest of the three ordinary classification levels: Confidential, Secret and Top Secret. SAPs do not create a fourth level above it. They add extra access, handling, marking and oversight controls around classified information when the normal rules for the same classification level are judged insufficient. Executive Order 13526 is explicit that, except where [statute]({{ 'statute/' | relative_url }}) provides otherwise, no other terms should be used to identify US classified information beyond the three levels it lists.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/isoo/policy-documents/cnsi-eo.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">cnsi eo</span><span class="citation-popover-snippet">National ArchivesThe President Executive Order 13526Dec 29, 2009 — This order prescribes a uniform system for classifying, safeguarding...</span></span></span>

The myth matters because it changes how people imagine secrecy works. “Above Top Secret” suggests a vertical ladder: climb high enough and everything becomes visible. SAP practice is closer to a locked room inside a building. A person may hold a [Top Secret clearance]({{ 'clearance-gap/' | relative_url }}) and still be outside a Top Secret SAP because they have not been approved for that particular programme and do not have a need to know. Official training material from the Defense [Counterintelligence]({{ 'ci-operations/' | relative_url }}) and Security Agency’s Center for Development of Security Excellence describes SAPs as programmes with safeguarding and access requirements exceeding those normally required for information at the same classification level, while also stating that SAPs use the standard classification levels of Top Secret, Secret and Confidential.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cdse.edu/Portals/124/Documents/student-guides/SA001-guide.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cdse.edu">[CDSE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cdse.edu</span><span class="citation-popover-snippet">Student Guide Course: Special Access Program (SAP)...February 4, 2020 — SAPs use the standard levels of classified information; that...</span><span class="citation-popover-meta">Published: February 4, 2020</span></span></span>

## Classification Level Versus Access Programme

The cleanest way to separate the concepts is to ask two different questions. Classification level answers: how much damage could unauthorised disclosure reasonably cause? Access programme answers: who, within the cleared population, may see this particular information and under what special controls?

Under Executive Order 13526, Top Secret applies when unauthorised disclosure could reasonably be expected to cause “exceptionally grave damage” to national security. Secret and Confidential correspond to lower stated damage thresholds. That is the classification ladder. SAPs sit across that ladder, not above it. A SAP can protect information that is Top Secret, Secret or Confidential, but the SAP label does not replace the underlying classification level.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://obamawhitehouse.archives.gov/the-press-office/executive-order-classified-national-security-information" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: obamawhitehouse.archives.gov">[archives.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">obamawhitehouse.archives.gov</span><span class="citation-popover-title">executive order classified national security information</span><span class="citation-popover-snippet">Order 13526- Classified National Security InformationDecember 29, 2009 — 29 Dec 2009 — Information may be classified at one of the follow...</span><span class="citation-popover-meta">Published: December 29, 2009</span></span></span>

Official SAP language repeatedly points to this distinction. CDSE’s SAP overview says SAPs are used when the ordinary rules for determining access to information “at the same level” are insufficient, and that a SAP is, in simple terms, a classified programme with enhanced safeguarding and access requirements. The [Intelligence]({{ 'intelligence/' | relative_url }}) Community markings register similarly describes [SAP markings]({{ 'markings/' | relative_url }}) as identifying information with special access requirements “not met by classification level, alone”.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cdse.edu/Portals/124/Documents/student-guides/SA001-guide.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cdse.edu">[CDSE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cdse.edu</span><span class="citation-popover-snippet">Student Guide Course: Special Access Program (SAP)...February 4, 2020 — SAPs use the standard levels of classified information; that...</span><span class="citation-popover-meta">Published: February 4, 2020</span></span></span>

That means a marking such as `TOP SECRET//SPECIAL ACCESS REQUIRED` should not be read as “higher than Top Secret”. It is better read as two signals joined together. “Top Secret” states the classification level. “Special Access Required” states that the holder also needs programme-specific authorisation, handling rules and a need to know. DoD marking guidance illustrates the same structure across classified documents: the banner line combines the classification level with control markings, dissemination controls or special access indicators rather than inventing a new classification tier.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.dodig.mil/Portals/48/Documents/Policy/520001_vol2.pdf?ver=2017-04-25-160926-223" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: dodig.mil">[DOD Intelligence Agency]</a><span class="citation-popover" role="note"><span class="citation-popover-source">dodig.mil</span><span class="citation-popover-title">520001 vol2</span><span class="citation-popover-snippet">520001 vol2</span></span></span>

A practical analogy is useful but imperfect: a university building may require a staff card to enter, while a laboratory inside it requires extra authorisation because of hazardous materials. The laboratory is not “above” the building; it is a more restricted space within it. In the same way, SAP access is a narrower permission inside the classified system, not a new rung above Top Secret.

## Why “Above Top Secret” Sounds Plausible

The myth persists because the lived experience of SAPs can feel higher than Top Secret. Someone with a Top Secret clearance may be denied access to a SAP, may not be allowed to confirm a programme’s existence, and may see markings or [codewords]({{ 'codewords/' | relative_url }}) that appear more exotic than ordinary classification labels. From the outside, those restrictions look like a higher classification level even when they are actually compartmentation.

This confusion is reinforced by the phrase “need to know”. A clearance establishes eligibility; it does not create universal access. A cleared person still needs an authorised reason to see particular information. For SAPs, that rule becomes more formal and more visible: access may require a [read-in]({{ 'read-in/' | relative_url }}), programme-specific non-disclosure obligations, special facilities, separate information systems and a documented access list. CDSE describes SAPs as requiring a nickname or codeword and special handling procedures in addition to the ordinary classification level.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cdse.edu/Portals/124/Documents/student-guides/SA001-guide.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cdse.edu">[CDSE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cdse.edu</span><span class="citation-popover-snippet">Student Guide Course: Special Access Program (SAP)...February 4, 2020 — SAPs use the standard levels of classified information; that...</span><span class="citation-popover-meta">Published: February 4, 2020</span></span></span>

The same pattern appears with Sensitive Compartmented Information, or SCI, which is often paired in public speech with “TS/SCI”. That abbreviation is another source of confusion. A Top Secret clearance with SCI eligibility does not mean the holder can see all SCI information; it means the person may be eligible for access to particular compartments when the need-to-know and approval requirements are met. A Congressional staff clearances primer from the Project On Government Oversight makes this point directly, noting that TS/SCI denotes a clearance level plus additional access requirements, not a blanket right to all compartmented intelligence.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://docs.pogo.org/report/2020/A_Primer_on_Congressional_Staff_Clearances_2020-02-05.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: docs.pogo.org">[docs.pogo.org]</a><span class="citation-popover" role="note"><span class="citation-popover-source">docs.pogo.org</span><span class="citation-popover-title">A Primer on Congressional Staff Clearances</span><span class="citation-popover-snippet">A Primer on Congressional Staff Clearances</span></span></span>

Public culture then compresses all of this into a simpler phrase. “Above Top Secret” is easier to say than “Top Secret information protected by a special access programme or compartmented control system with additional eligibility, handling and dissemination restrictions.” The shorter phrase captures the sense of greater restriction, but it misstates the legal and administrative mechanism.

## Waived and Unacknowledged SAPs Do Not Create a Higher Tier

The terms “unacknowledged” and “waived” can make the myth stronger because they sound like levels deeper than Top Secret. They are not classification levels either. They describe how a SAP’s existence and reporting are handled.

An acknowledged SAP may have an existence that can be admitted, even though its details remain classified. An unacknowledged SAP is more sensitive because even the fact of its existence is controlled. A waived SAP is a narrower category in Department of Defense practice: current DoD instruction says the Secretary of Defense may designate selected unacknowledged SAPs as waived when ordinary congressional reporting procedures would adversely affect national security, while adding that waived SAPs remain subject to congressional oversight.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.esd.whs.mil/Portals/54/Documents/DD/issuances/dodi/520511p.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: esd.whs.mil">[WHS ESD]</a><span class="citation-popover" role="note"><span class="citation-popover-source">esd.whs.mil</span><span class="citation-popover-snippet">Open source on whs.mil.</span></span></span>

This matters because “unacknowledged” is sometimes taken to mean “outside the system”. The official language points the other way. Waived SAPs are defined inside statute and DoD policy; they are not a free-standing classification above Top Secret. The relevant legal provision, 10 U.S.C. §119, concerns congressional oversight of special access programmes, while related provisions on alternative compensatory control measures also show Congress legislating for special control regimes without converting them into new classification levels.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.govinfo.gov/content/pkg/USCODE-2019-title10/html/USCODE-2019-title10-subtitleA-partI-chap2.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: govinfo.gov">[GovInfo]</a><span class="citation-popover" role="note"><span class="citation-popover-source">govinfo.gov</span><span class="citation-popover-title">USCODE 2019 title10 subtitleA partI chap2</span><span class="citation-popover-snippet">USCODE 2019 title10 subtitleA partI chap2</span></span></span>

The more accurate reading is therefore: waived and unacknowledged SAPs can be more restricted in acknowledgement, access and reporting, but the underlying information still carries a recognised classification level. The restriction is horizontal compartmentation and controlled reporting, not a vertical leap above Top Secret.

## How to Read Official Language Without Falling for the Myth

Official documents usually reveal the difference if read carefully. The key is to separate damage language, access language and marking language.

**Classification language** uses words such as Confidential, Secret and Top Secret. It usually links those labels to expected damage from unauthorised disclosure. Executive Order 13526 and [ISOO]({{ 'isoo/' | relative_url }}) guidance both frame the classification levels in this way, with Top Secret tied to exceptionally grave damage.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/isoo/policy-documents/cnsi-eo.html" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">cnsi eo</span><span class="citation-popover-snippet">National ArchivesThe President Executive Order 13526Dec 29, 2009 — This order prescribes a uniform system for classifying, safeguarding...</span></span></span>

**Access-control language** uses phrases such as special access required, sensitive compartmented information, need to know, read-in, programme access, eligibility, compartment, nickname, codeword and safeguarding. Those words tell the reader that ordinary clearance eligibility is not enough. They do not, by themselves, establish a new classification level.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cdse.edu/Portals/124/Documents/student-guides/SA001-guide.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cdse.edu">[CDSE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cdse.edu</span><span class="citation-popover-snippet">Student Guide Course: Special Access Program (SAP)...February 4, 2020 — SAPs use the standard levels of classified information; that...</span><span class="citation-popover-meta">Published: February 4, 2020</span></span></span>

**Oversight language** uses terms such as acknowledged, unacknowledged, waived, congressional notification, annual report and programme establishment. These terms describe who is told, when they are told and through which channel. They may indicate a highly sensitive programme, but they still do not mean “higher than Top Secret”.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.esd.whs.mil/Portals/54/Documents/DD/issuances/dodi/520511p.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: esd.whs.mil">[WHS ESD]</a><span class="citation-popover" role="note"><span class="citation-popover-source">esd.whs.mil</span><span class="citation-popover-snippet">Open source on whs.mil.</span></span></span>

A useful rule is: if the phrase answers “how damaging would disclosure be?”, it is probably classification language. If it answers “who may access this and under what restrictions?”, it is probably access-control language. If it answers “who may be told that the programme exists?”, it is oversight or acknowledgement language.

## The Myth’s Practical Cost

Calling SAPs “above Top Secret” is not just a harmless shortcut. It can make secrecy sound more mysterious and less governed than the public record supports. The open rules show a structured system: classification levels, special access controls, approval processes, marking conventions and congressional reporting requirements. That structure can still be controversial, especially where access is very narrow, costs are hidden or oversight is limited, but the controversy is about control and accountability rather than a secret fourth classification level.

The myth also encourages a mistaken idea of clearance as rank. In reality, clearance is only one part of access. A person may be eligible for Top Secret information in general and still be excluded from a SAP because they are not assigned to the programme. Conversely, SAP material is not automatically more damaging than every other Top Secret item simply because it is compartmented; it is being protected through additional controls because ordinary access rules are judged inadequate for that programme or information set.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cdse.edu/Portals/124/Documents/student-guides/SA001-guide.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cdse.edu">[CDSE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cdse.edu</span><span class="citation-popover-snippet">Student Guide Course: Special Access Program (SAP)...February 4, 2020 — SAPs use the standard levels of classified information; that...</span><span class="citation-popover-meta">Published: February 4, 2020</span></span></span>

The more precise wording is less dramatic but more useful: SAPs are special access and safeguarding regimes applied to classified information, often including Top Secret information, when normal classification-level controls are not enough. That is why the phrase “above Top Secret” should be treated as popular shorthand, not as a description of how the official system is built.

  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
</script>
