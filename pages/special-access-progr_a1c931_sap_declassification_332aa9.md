## Introduction

Public declassification plans for special-access-programmes, or SAPs, show an important but often missed point: special access is not always meant to be permanent. A SAP can move from unacknowledged to acknowledged, from SAP controls to ordinary classified handling, or from classified status into public release. In the United States, that transition is not supposed to be improvised at a press conference. For Department of Defense SAPs, law and policy require advance reporting to the defence committees when a classification change, declassification, or public announcement is planned; the report must explain the proposed change, the reasons for it, and any planned public announcement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">Open source on house.gov.</span></span></span>



<img src="{{ "/assets/images/special-access-progr_a1c931_sap_declassification_332aa9-overview.webp" | relative_url }}" alt="Overview image for Declassification" loading="eager" decoding="sync" fetchpriority="high">

That does not mean the whole programme becomes public. It means secrecy can be staged: the government may acknowledge a platform, disclose costs, release a museum aircraft, or publish a historical account while still protecting performance data, sources, methods, vulnerabilities, operational lessons, or related [compartments]({{ 'compartments/' | relative_url }}).

## Planned public declassification is a managed transition

The clearest public rule appears in the Department of Defense SAP framework. DoD policy says SAP controls should be used only when ordinary need-to-know controls are not enough, because the threat, vulnerability, sensitivity, or statutory requirement is exceptional. The same older DoD information-security regulation then describes what happens when that exceptional need changes: components intending to downgrade a SAP, move it from unacknowledged to acknowledged status, remove enhanced SAP controls, declassify a programme, or make a public announcement must prepare congressional notification letters.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://irp.fas.org/doddir/dod/5200-1r/chapter_8.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: irp.fas.org">[Intelligence Resource Program]</a><span class="citation-popover" role="note"><span class="citation-popover-source">irp.fas.org</span><span class="citation-popover-title">Intelligence Resource Program Chapter 8</span><span class="citation-popover-snippet">Intelligence Resource Program Chapter 8</span></span></span>

That notification requirement is unusually revealing. It treats public release as one possible point on a formal life cycle, alongside downgrading, termination and transition to collateral classified handling. The required letter is not merely a public-relations note. It must describe the proposed change, give the reasons for it, and give notice of any planned public announcement. DoD policy also states that no action or announcement should occur sooner than 14 days after delivery to the appropriate congressional committees, unless a statutory exception applies.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://irp.fas.org/doddir/dod/5200-1r/chapter_8.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: irp.fas.org">[Intelligence Resource Program]</a><span class="citation-popover" role="note"><span class="citation-popover-source">irp.fas.org</span><span class="citation-popover-title">Intelligence Resource Program Chapter 8</span><span class="citation-popover-snippet">Intelligence Resource Program Chapter 8</span></span></span>

The [statute]({{ 'statute/' | relative_url }}) for DoD SAP oversight uses the same basic model. Under 10 U.S.C. § 119, whenever a change in classification is planned, or classified information about a DoD SAP is to be declassified and made public, the Secretary of Defense must report to the defence committees at least 14 days before the planned change or public announcement, except in exceptional circumstances.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">Open source on house.gov.</span></span></span> [Intelligence]({{ 'intelligence/' | relative_url }})-related law contains a parallel rule for certain intelligence special-access or covered programmes: when classification is to change, or information is to be declassified and made public, the relevant head must report the proposed change or information to be declassified, explain the reasons, and identify any public announcement.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?req=%28title%3A50+section%3A3348+edition%3Aprelim%29" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">Open source on house.gov.</span></span></span>

This is the core distinction between “classified today” and “classified forever”. SAP status is designed around present risk. When the risk calculus changes because a system is already fielded, an adversary already knows enough, a programme is being cancelled, congressional and public [accountability]({{ 'accountability/' | relative_url }}) pressures rise, or historical value outweighs remaining secrecy, public declassification can become part of the plan rather than a breach of it.

## The release can be partial, not total

A planned SAP declassification usually does not mean every fact behind the programme is released. Executive Order 13526 states that information should be declassified as soon as it no longer meets the standards for classification, but it also allows agencies to keep information classified where release could still cause identifiable national-security damage. It requires periodic classification-guidance reviews to identify information that no longer needs protection and says mandatory declassification review should release information unless withholding is otherwise authorised and warranted.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://obamawhitehouse.archives.gov/the-press-office/executive-order-classified-national-security-information" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: obamawhitehouse.archives.gov">[whitehouse.gov]</a><span class="citation-popover" role="note"><span class="citation-popover-source">obamawhitehouse.archives.gov</span><span class="citation-popover-title">executive order classified national security information</span><span class="citation-popover-snippet">executive order classified national security information</span></span></span>

For SAPs, the practical result is layered disclosure. A government may reveal that a programme existed, release a name or aircraft shape, permit an unclassified audit, or place an artefact in a museum, while leaving technical performance, countermeasures, signatures, mission tactics, intelligence sources, procurement vulnerabilities, or related compartments classified. DoD’s older SAP transition rule makes this explicit: termination or transition plans should identify what information will remain classified and what operational-security measures will still protect sensitive unclassified indicators or methods associated with the former SAP.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://irp.fas.org/doddir/dod/5200-1r/chapter_8.htm" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: irp.fas.org">[Intelligence Resource Program]</a><span class="citation-popover" role="note"><span class="citation-popover-source">irp.fas.org</span><span class="citation-popover-title">Intelligence Resource Program Chapter 8</span><span class="citation-popover-snippet">Intelligence Resource Program Chapter 8</span></span></span>

The B-2 bomber is a good example of partial opening. In 1990, the Government Accountability Office issued its first unclassified report on the B-2, explaining that previous aspects of the programme had been highly classified and that recent classification changes allowed public reporting on history, cost, schedule and test status. At the same time, GAO said performance information remained classified and would be handled separately.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.gao.gov/assets/nsiad-90-120.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: gao.gov">[GAO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">gao.gov</span><span class="citation-popover-title">NSIAD-90-120 Strategic Bombers: B-2 Program Status and Current Issues</span><span class="citation-popover-snippet">NSIAD-90-120 Strategic Bombers: B-2 Program Status and Current Issues</span></span></span> The public gained a real view of programme cost, schedule risk and [acquisition]({{ 'acquisition/' | relative_url }}) controversy, but not the full technical picture that would matter most to adversaries.

The same pattern appears in public aviation history. The B-2 was shown publicly at Air Force Plant 42 on 22 November 1988 in front of members of [Congress]({{ 'congress/' | relative_url }}) and the media, even though it had been developed in great secrecy and had not yet made its first test flight.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.history.com/this-day-in-history/november-22/stealth-bomber-unveiled" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: history.com">[History]</a><span class="citation-popover" role="note"><span class="citation-popover-source">history.com</span><span class="citation-popover-title">Stealth bomber unveiled</span><span class="citation-popover-snippet">Stealth bomber unveiled</span></span></span> Tacit Blue, a [stealth]({{ 'stealth/' | relative_url }}) technology demonstrator, followed a different route: it flew 135 times, ended in 1985, and was declassified and placed on display at the National Museum of the United States Air Force in 1996.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.nationalmuseum.af.mil/Visit/Museum-Exhibits/Fact-Sheets/Display/Article/195769/northrop-tacit-blue/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: nationalmuseum.af.mil">[Air Force Museum]</a><span class="citation-popover" role="note"><span class="citation-popover-source">nationalmuseum.af.mil</span><span class="citation-popover-snippet">Northrop Tacit Blue &gt; National Museum of the United States Air Force &gt; Display...</span></span></span> The public release of Tacit Blue allowed a once-hidden technology lineage to become part of official history without implying that every related stealth technique or operational application had become harmless to disclose.

## What may remain classified after public acknowledgement

The most common misunderstanding is to treat public acknowledgement as a magic switch. In SAP practice, the switch is more selective. A programme can be acknowledged while its detailed records still carry [SAP markings]({{ 'markings/' | relative_url }}), or it can leave SAP channels while some information remains classified at the collateral level. A declassified museum display, a public fact sheet, or an unclassified budget discussion is not the same as blanket permission to disclose everything remembered by former participants.

Several categories commonly remain protected even after a SAP-related public release:

* **Performance details:** range, signature data, sensor limits, survivability assumptions, communications vulnerabilities and test anomalies may remain classified because they help adversaries build countermeasures.
* **Operational methods:** tactics, deployment patterns, mission planning assumptions, maintenance practices and recovery procedures may reveal how a capability is actually used.
* **Compartment links:** one disclosed programme may be connected to still-classified subcompartments, successor systems, intelligence sources or foreign-partner arrangements.
* **Procurement and industrial-security details:** supplier vulnerabilities, anti-tamper measures, manufacturing processes and classified contract structures may remain sensitive after the headline programme is public.
* **Residual SAP handling obligations:** public disclosure approval is not identical to declassification, and cleared personnel may still need written authorisation before using SAP-derived information in public material. CDSE training warns that approval to disclose SAP information publicly does not automatically mean the information is declassified or that individuals may confirm, deny or disclose related information on their own.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cdse.edu/Portals/124/Documents/student-guides/SA002-guide.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cdse.edu">[CDSE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cdse.edu</span><span class="citation-popover-title">Special Access Program Security Annual Refresher</span><span class="citation-popover-snippet">Special Access Program Security Annual Refresher</span></span></span>

Even document markings reflect this long tail. CDSE’s 2025 SAP markings guide explains that SAP banner lines include the classification level, the “SPECIAL ACCESS REQUIRED” or “SAR” caveat, and the programme nickname or codeword. The same guide shows that SAP documents may be eligible for a 50-year declassification instruction under a file-series exemption, making their declassification date 31 December fifty years after original classification in the training example.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cdse.edu/Portals/124/Documents/student-guides/shorts/SAS0030-guide.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cdse.edu">[CDSE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cdse.edu</span><span class="citation-popover-title">Speical Access Programs: Markings Short</span><span class="citation-popover-snippet">Speical Access Programs: Markings Short</span></span></span> That does not mean every SAP record waits exactly fifty years; it shows that SAP information can sit inside longer declassification timelines than ordinary twenty-five-year assumptions when approved exemptions apply.

## Why timing matters

Timing is not a cosmetic issue in SAP declassification. Releasing a programme too early can reveal a capability while it is still operationally fragile. Releasing too late can damage oversight, inflate costs, hide duplication, frustrate allies and contractors, and prevent the public from understanding major national-security decisions after the original risk has faded.

The B-2 illustrates the accountability side of timing. Once classification changes allowed GAO to publish an unclassified report, public debate could focus on cost growth, schedule uncertainty, procurement assumptions and the fact that testing had only just begun. GAO’s report noted that the programme had been the subject of classified reports since 1986 and that the unclassified release drew on information that had since become releasable.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.gao.gov/assets/nsiad-90-120.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: gao.gov">[GAO]</a><span class="citation-popover" role="note"><span class="citation-popover-source">gao.gov</span><span class="citation-popover-title">NSIAD-90-120 Strategic Bombers: B-2 Program Status and Current Issues</span><span class="citation-popover-snippet">NSIAD-90-120 Strategic Bombers: B-2 Program Status and Current Issues</span></span></span> The timing mattered because the programme was still politically and financially contested; public declassification did not simply serve history, it affected contemporary oversight.

Tacit Blue shows the historical side. By the time it was declassified and displayed in 1996, the aircraft had long stopped flying, and its value as an official explanation of stealth development had increased. DARPA now describes Tacit Blue as a stepping stone whose stealth, radar and aerodynamic innovations helped lay foundations for the B-2.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.darpa.mil/about/innovation-timeline/tacit-blue" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: darpa.mil">[darpa.mil]</a><span class="citation-popover" role="note"><span class="citation-popover-source">darpa.mil</span><span class="citation-popover-title">Tacit Blue &#124; DARPA</span><span class="citation-popover-snippet">Tacit Blue &#124; DARPA</span></span></span> The public release turned a hidden demonstrator into a visible link in the technology chain, while the long delay reduced the immediate operational risk of revealing its shape and purpose.

Recent space-classification reform shows that timing is also a live governance problem, not just a Cold War story. In 2024, DefenseScoop reported that the Department of Defense revised space-programme classification policy to reduce access barriers and address concerns that overuse of SAP designations impaired collaboration with allies, industry and other stakeholders.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://defensescoop.com/2024/01/18/defense-department-policy-classified-space-programs/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: defensescoop.com">[DefenseScoop]</a><span class="citation-popover" role="note"><span class="citation-popover-source">defensescoop.com</span><span class="citation-popover-snippet">Open source on defensescoop.com.</span></span></span> That kind of reform is not necessarily “declassification” in the museum-display sense, but it sits on the same spectrum: deciding when special access has become more harmful than helpful for a mission that requires wider coordination.

## Public release does not erase oversight gaps

Planned public declassification improves accountability, but it does not solve every oversight problem created by SAP compartmentation. Congressional notice before a public announcement gives committees a formal warning and an opportunity to question timing, scope and residual secrecy. Yet much of the meaningful debate may still occur in classified channels, and the public may see only the final sanitised version.

The Public Interest Declassification Board has warned more broadly that classified congressional records are often difficult for the public and historians to access. Its report noted that closed national-security hearings may be the only occasions where executive-branch policy is explained, challenged and defended, but the resulting committee records can remain classified or outside ordinary declassification processes.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.archives.gov/files/declassification/pidb/improving-declassification.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: archives.gov">[National Archives]</a><span class="citation-popover" role="note"><span class="citation-popover-source">archives.gov</span><span class="citation-popover-title">National Archives BIPD 1</span><span class="citation-popover-snippet">National Archives BIPD 1</span></span></span> For SAPs, this matters because the most important accountability record may not be the eventual public announcement. It may be the classified discussion beforehand: why a programme stayed hidden, why it was acknowledged at a particular moment, what remained withheld, and whether Congress accepted the executive branch’s reasoning.

This is why a public declassification plan should be read as a governance instrument, not merely as a secrecy rollback. It establishes who must be told before release, what rationale must be written down, what material will be exposed, and what protections will survive. Done well, it lets a programme move from exceptional secrecy into public knowledge without pretending that every sensitive detail has expired. Done poorly, it can reveal too little for accountability while still disclosing enough to create security risk.

## The practical takeaway

Public declassification plans for SAPs sit between two false assumptions. The first is that a SAP is a permanent black hole. The second is that once a programme is publicly acknowledged, its secrets are over. The open legal and policy record supports a more precise view: SAPs can be downgraded, transitioned, terminated, acknowledged, or partially declassified through planned processes that include congressional notice and residual protection decisions.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://uscode.house.gov/view.xhtml?edition=prelim&amp;num=0&amp;req=granuleid%3AUSC-prelim-title10-section119" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: uscode.house.gov">[U.S. Code]</a><span class="citation-popover" role="note"><span class="citation-popover-source">uscode.house.gov</span><span class="citation-popover-snippet">Open source on house.gov.</span></span></span>

The most useful question is therefore not simply “has this SAP been declassified?” It is “which layer has changed?” A name, existence statement, cost history, aircraft display, operational capability, technical performance figure and archived congressional record can all have different release dates. That staged pattern is what makes public declassification plans distinctive within the wider world of special-access-programmes, including waived and unacknowledged programmes: they show how secrecy can be deliberately unwound without assuming that every protected fact becomes public at the same time.

  function buildUrl(query, reference, marketId) {
    var cfg = markets[marketId] || markets[defaultMarket];
    if (!cfg) return '#';
    var template = String(cfg.url_template || 'https://www.ebay.com/sch/i.html?_nkw={query}');
    var url = template.replace('{query}', encodeQuery(query || '')).replace('{query_plain}', String(query || ''));
    var joiner = url.indexOf('?') >= 0 ? '&' : '?';
    var params = [];
    if (cfg.mkrid) params.push('mkrid=' + encodeURIComponent(cfg.mkrid));
    if (cfg.campaign_id) params.push('campid=' + encodeURIComponent(cfg.campaign_id));
    params.push('mkevt=1');
    params.push('mkcid=1');
    params.push('toolid=' + encodeURIComponent(cfg.tool_id || '10001'));
    if (reference) params.push('customid=' + encodeURIComponent(reference).slice(0, 256));
    return url + joiner + params.join('&');
  }
  function domainLabel(marketId) {
    var cfg = markets[marketId] || markets[defaultMarket] || {};
    return cfg.domain_label || 'eBay';
  }
  function flagClass(marketId) {
    return 'fr-ebay-market-flag fr-ebay-market-flag--' + String(marketId || '').toLowerCase().replace(/_/g, '-').replace(/[^a-z0-9-]+/g, '');
  }
  function closeMenu(section) {
    var menu = section.querySelector('[data-ebay-market-menu]');
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var picker = section.querySelector('.fr-ebay-market-picker');
    if (menu) menu.hidden = true;
    if (trigger) trigger.setAttribute('aria-expanded', 'false');
    if (picker) picker.classList.remove('fr-ebay-market-picker--open');
  }
  function availableMarkets(section) {
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      return Array.prototype.slice.call(select.options)
        .map(function (option) { return option.value; })
        .filter(function (marketId) { return !!markets[marketId]; });
    }
    return Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]'))
      .map(function (button) { return button.getAttribute('data-ebay-market-button'); })
      .filter(function (marketId) { return !!markets[marketId]; });
  }
  function applyMarket(section, marketId, persist) {
    var available = availableMarkets(section);
    if (available.indexOf(marketId)< 0) marketId = available[0] || defaultMarket;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-localized-link]')).forEach(function (link) {
      var query = link.getAttribute('data-ebay-query') || '';
      var reference = link.getAttribute('data-ebay-reference') || '';
      link.setAttribute('href', buildUrl(query, reference, marketId));
    });
    var select = section.querySelector('[data-ebay-market-select]');
    if (select && available.indexOf(marketId) >= 0) select.value = marketId;
    var selectedText = marketId;
    if (select && select.selectedIndex >= 0) selectedText = select.options[select.selectedIndex].text;
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-selected-market-flag], [data-ebay-trigger-market-flag]')).forEach(function (flag) {
      flag.className = flagClass(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-trigger-market-label]')).forEach(function (label) {
      label.textContent = selectedText;
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-domain-label]')).forEach(function (label) {
      label.textContent = domainLabel(marketId);
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
      button.setAttribute('aria-selected', button.getAttribute('data-ebay-market-option') === marketId ? 'true' : 'false');
    });
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      var active = button.getAttribute('data-ebay-market-button') === marketId;
      button.setAttribute('aria-pressed', active ? 'true' : 'false');
    });
    section.setAttribute('data-ebay-selected-market', marketId);
    if (persist) {
      try { if (window.localStorage) localStorage.setItem('phoenix-ebay-market', marketId); } catch (err) {}
    }
    closeMenu(section);
  }
  sections.forEach(function (section) {
    if (section.getAttribute('data-ebay-localized-init') === '1') return;
    section.setAttribute('data-ebay-localized-init', '1');
    var available = availableMarkets(section);
    var marketId = defaultMarket;
    if (window.PhoenixAffiliateLocation && window.PhoenixAffiliateLocation.inferMarket) {
      marketId = window.PhoenixAffiliateLocation.inferMarket(available, {
        storageKey: 'phoenix-ebay-market',
        defaultMarket: defaultMarket
      });
    } else if (available.indexOf(defaultMarket)< 0) {
      marketId = available[0] || defaultMarket;
    }
    var select = section.querySelector('[data-ebay-market-select]');
    if (select) {
      select.addEventListener('change', function () {
        applyMarket(section, select.value, true);
      });
    }
    var trigger = section.querySelector('[data-ebay-market-trigger]');
    var menu = section.querySelector('[data-ebay-market-menu]');
    if (trigger && menu) {
      trigger.addEventListener('click', function (event) {
        event.stopPropagation();
        var expanded = trigger.getAttribute('aria-expanded') === 'true';
        menu.hidden = expanded;
        trigger.setAttribute('aria-expanded', expanded ? 'false' : 'true');
        var picker = trigger.closest('.fr-ebay-market-picker');
        if (picker) picker.classList.toggle('fr-ebay-market-picker--open', !expanded);
      });
      Array.prototype.slice.call(menu.querySelectorAll('[data-ebay-market-option]')).forEach(function (button) {
        button.addEventListener('click', function (event) {
          event.stopPropagation();
          applyMarket(section, button.getAttribute('data-ebay-market-option'), true);
        });
      });
      document.addEventListener('click', function () { closeMenu(section); });
    }
    Array.prototype.slice.call(section.querySelectorAll('[data-ebay-market-button]')).forEach(function (button) {
      button.addEventListener('click', function () {
        applyMarket(section, button.getAttribute('data-ebay-market-button'), true);
      });
    });
    applyMarket(section, marketId, false);
  });
})();
</script>
