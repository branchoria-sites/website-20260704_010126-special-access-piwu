## Introduction

Waived Special Access Programmes (SAPs) represent the narrowest form of congressional reporting within the United States Department of Defense's special-access system. They do not eliminate congressional oversight, but they significantly reduce the number of legislators and staff who are routinely informed about a programme's existence or details. This distinction is central to understanding the governance debate surrounding extreme secrecy. Rather than asking whether [Congress]({{ 'congress/' | relative_url }}) has any oversight at all, the more important question is who is able to exercise that oversight, with what information, and under what constraints.

Within the broader critique developed by Senator Daniel Patrick Moynihan's Commission on Protecting and Reducing Government Secrecy, waived SAPs illustrate how secrecy can preserve formal [accountability]({{ 'accountability/' | relative_url }}) while concentrating practical oversight in the hands of a very small number of officials. ## What waiver changes in reporting practice

A waived SAP is not a separate category of classified information but a subset of unacknowledged Department of Defense SAPs. Its defining feature is that the Secretary of Defense determines that following the normal statutory reporting procedures would itself pose an unacceptable risk to national security. Under those exceptional circumstances, reporting requirements may be waived pursuant to federal law.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.esd.whs.mil/Portals/54/Documents/DD/issuances/dodi/520511p.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: esd.whs.mil">[WHS ESD]</a><span class="citation-popover" role="note"><span class="citation-popover-source">esd.whs.mil</span><span class="citation-popover-snippet">g. DoD will share DoD SAP-protected information to the greatest extent practicable with.Read more...</span></span></span>

In practical terms, the waiver changes congressional notification rather than eliminating it.

Instead of the broader reporting channels used for ordinary SAPs:

* notification is limited to a very small group of senior congressional leaders from the defence oversight committees;
* access by [committee staff]({{ 'staff-access/' | relative_url }}) is similarly restricted unless specifically approved;
* handling procedures are tightened, with particularly sensitive material often remaining under Department of Defense custody rather than being routinely retained by congressional offices.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.dami.army.pentagon.mil/site/sci/docs/DoD%205205_07.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: dami.army.pentagon.mil">[dami.army.pentagon.mil]</a><span class="citation-popover" role="note"><span class="citation-popover-source">dami.army.pentagon.mil</span><span class="citation-popover-snippet">DoD Directive 5205.07, July 1, 2010July 6, 2010 — by DD SAPCO · 2010 — All waived SAP material submitted to Congress, to include annual r...</span><span class="citation-popover-meta">Published: July 1, 2010</span></span></span>

Current Department of Defense policy is explicit that waived SAPs remain subject to congressional oversight despite these exceptional reporting arrangements. The waiver therefore modifies the mechanism of oversight rather than creating a programme entirely outside constitutional accountability.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.esd.whs.mil/Portals/54/Documents/DD/issuances/dodi/520511p.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: esd.whs.mil">[WHS ESD]</a><span class="citation-popover" role="note"><span class="citation-popover-source">esd.whs.mil</span><span class="citation-popover-snippet">g. ## Why fewer informed legislators changes oversight

The governance challenge arises because oversight depends on more than formal legal authority. It also depends on the number of people who can ask informed questions, compare programmes and identify inconsistencies.

When knowledge is concentrated among only a handful of legislators:

* independent cross-checking becomes more difficult;
* institutional memory depends heavily on a small number of individuals;
* turnover through elections or committee changes can rapidly reduce accumulated expertise;
* fewer members can compare one highly classified programme against another when considering [budgets]({{ 'budgets/' | relative_url }}), [duplication]({{ 'duplication/' | relative_url }}) or strategic priorities.

These effects do not necessarily imply abuse. Instead, they illustrate a structural feature of extreme secrecy: reducing the audience capable of evaluating official claims also reduces the diversity of perspectives brought to oversight.

The Moynihan Commission repeatedly argued that excessive secrecy creates governance costs precisely because information needed for accountability becomes concentrated inside increasingly narrow administrative circles. ## The narrow reporting problem in practice

The reporting problem is best understood as a difference between **legal oversight** and **effective oversight**.

Legally, Congress retains authority over defence appropriations, programme authorisation and executive accountability. The executive branch cannot simply declare that a waived SAP is beyond congressional control.

Practically, however, the people exercising that authority may be reduced to only a few committee leaders operating under strict security rules. Those members may have limited ability to:


<div class="content-enhancement content-enhancement--comparison" markdown="1">

* consult outside technical experts;
* discuss concerns with other legislators;
* build broader political support for questioning a programme;
* compare classified information across multiple portfolios.

</div>

This concentration increases reliance on trust between the executive branch and a very small oversight audience. It also makes external verification substantially harder, since most legislators—and almost all of the public—cannot independently assess whether executive descriptions are complete or whether programme risks are adequately represented.

## How current policy seeks to preserve oversight

Modern Department of Defense policy attempts to balance extraordinary secrecy with continued institutional accountability.

Several safeguards remain in place despite the waiver:

* **Secretary-level approval.** Waived status requires a determination by the Secretary of Defense that ordinary reporting would itself harm national security.
* **Congressional notification through restricted channels.** Oversight is narrowed but not removed.
* **Internal governance.** SAPs operate within a formal oversight structure that includes designated oversight authorities, Special Access Program Central Offices (SAPCOs), review groups and lifecycle management requirements.
* **Periodic review.** Department policy requires continuing management of SAPs and planning for eventual reduction or removal of SAP protections when extraordinary controls are no longer justified. Executive Order 13526 likewise requires annual review of special access programmes to ensure they continue to meet the required standards.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.esd.whs.mil/Portals/54/Documents/DD/issuances/dodi/520511p.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: esd.whs.mil">[WHS ESD]</a><span class="citation-popover" role="note"><span class="citation-popover-source">esd.whs.mil</span><span class="citation-popover-snippet">g. DoD will share DoD SAP-protected information to the greatest extent practicable with.Read more...</span></span></span>

These mechanisms reflect an important policy principle: exceptional secrecy is intended to be exceptional in both scope and duration, not a permanent exemption from governance.

## Why the debate persists

Supporters of waived SAPs argue that some capabilities are so sensitive that even wider congressional reporting could increase operational risk. Highly advanced military technologies, exceptionally sensitive [intelligence]({{ 'intelligence/' | relative_url }}) support and certain covert capabilities may depend upon extremely small circles of knowledge until deployment or public acknowledgement becomes feasible. From this perspective, narrowing reporting is itself a protective measure rather than an attempt to avoid accountability.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.cdse.edu/Portals/124/Documents/student-guides/SA001-guide.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: cdse.edu">[CDSE]</a><span class="citation-popover" role="note"><span class="citation-popover-source">cdse.edu</span><span class="citation-popover-snippet">Student Guide Course: Special Access Program (SAP)...Waived SAPs are unacknowledged SAPs for which the Secretary of Defense has waiv...</span></span></span>

Critics respond that every reduction in the number of informed overseers increases dependence on executive self-reporting. They argue that secrecy may unintentionally reduce opportunities to identify cost overruns, duplicated research, changing strategic assumptions or outdated security restrictions. This concern closely parallels the Moynihan Commission's broader warning that secrecy should always be evaluated not only for its protective value but also for its institutional costs.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://fas.org/publication/dod_saps/" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: fas.org">[Federation of American Scientists]</a><span class="citation-popover" role="note"><span class="citation-popover-source">fas.org</span><span class="citation-popover-title">dod saps</span><span class="citation-popover-snippet">Federation of American ScientistsSpotlight on DoD Special Access Programs7 Feb 2013 — “Waived SAPs” are the most sensitive of special acc...</span></span></span>

## The governance lesson

Waived SAPs demonstrate that oversight is not simply a binary question of whether Congress is informed. The more consequential issue is how many people possess enough information to exercise meaningful scrutiny.

Current law and Department of Defense policy preserve congressional oversight even for waived programmes, but they do so through deliberately narrowed reporting channels. That design reflects a conscious trade-off: protecting exceptionally sensitive national security information while accepting that effective oversight will be concentrated among a very small group of trusted officials.

From the perspective of the Moynihan critique, this concentration is the central governance issue. Formal accountability survives, yet the capacity for challenge, comparison and institutional learning becomes progressively narrower as secrecy intensifies.<span class="citation-link-wrap"><a class="citation-inline-link" href="https://www.esd.whs.mil/Portals/54/Documents/DD/issuances/dodi/520511p.pdf" target="_blank" rel="noopener noreferrer nofollow" aria-label="View source: esd.whs.mil">[whs.mil]</a><span class="citation-popover" role="note"><span class="citation-popover-source">esd.whs.mil</span><span class="citation-popover-snippet">g.       else if (navigator.language) languages = [navigator.language];
    } catch (err) {}
    for (var i = 0; i< languages.length; i += 1) {
      var normalized = normalize(languages[i]);
      if (!normalized) continue;
      if (localeMarketMap[normalized]) {
        exactMarket = localeMarketMap[normalized];
        break;
      }
      var languageOnly = normalized.split('-')[0];
      if (!languageMarket && localeMarketMap[languageOnly]) languageMarket = localeMarketMap[languageOnly];
    }
    return { exact: exactMarket, language: languageMarket };
  }
  function inferFromLocale() {
    var matches = localeMatches();
    return matches.exact || matches.language || '';
  }
  function inferFromTimezone() {
    var tz = '';
    try { tz = String(Intl.DateTimeFormat().resolvedOptions().timeZone || ''); } catch (err) {}
    if (!tz) return '';
    for (var i = 0; i< timezoneRules.length; i += 1) {
      var rule = timezoneRules[i] || {};
      try {
        if (new RegExp(rule.pattern).test(tz)) return rule.market;
      } catch (err) {}
    }
    return '';
  }
  function inferMarket(available, options) {
    available = Array.isArray(available) ? available : [];
    options = options || {};
    var storageKey = options.storageKey || 'phoenix-affiliate-market';
    try {
      var saved = window.localStorage && localStorage.getItem(storageKey);
      if (saved && available.indexOf(saved) >= 0) return saved;
    } catch (err) {}
    var timezoneMarket = inferFromTimezone();
    if (timezoneMarket && available.indexOf(timezoneMarket) >= 0) return timezoneMarket;
    var localeMarkets = localeMatches();
    if (localeMarkets.exact && available.indexOf(localeMarkets.exact) >= 0) return localeMarkets.exact;
    if (localeMarkets.language && available.indexOf(localeMarkets.language) >= 0) return localeMarkets.language;
    if (options.defaultMarket && available.indexOf(options.defaultMarket) >= 0) return options.defaultMarket;
    return available[0] || '';
  }
  window.PhoenixAffiliateLocation = {
    normalize: normalize,
    inferMarket: inferMarket,
    inferFromLocale: inferFromLocale,
    inferFromTimezone: inferFromTimezone
  };
})();
